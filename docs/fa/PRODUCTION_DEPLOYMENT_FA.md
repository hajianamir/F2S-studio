# معماری استقرار تولید و چند مستأجری (اجرای مسیر ۱)

## ۱. مایلستون‌ها، پایش پلتفرم و چک‌لیست راه‌اندازی مرحله ۱
- **تاریخ تصمیم‌گیری Go/No-Go**: **۸ ژانویه ۲۰۲۷** | **تاریخ راه‌اندازی**: **۱۵ ژانویه ۲۰۲۷**.
- **شفاف‌سازی وضعیت استقرار (رفع R-105 و R-106 - گزینه B)**:
  - *وضعیت فعلی استقرار*: **گزینه B — ارزیابی محلی Docker Compose**. پیکربندی استقرار در محیط ایزوله کاملاً تست شده و استقرار روی AWS برای ۱۵ ژانویه ۲۰۲۷ برنامه‌ریزی گردیده است.
  - *وضعیت مانور ورود مهندس ناظر*: **گزینه B — بازسازی مستند گردش‌کار**. مراحل پنج‌گانه ورود مهندس ناظر به عنوان راهنمای گردش‌کار تدوین گردیده و ورود واقعی برای ۲۲ ژانویه ۲۰۲۷ برنامه‌ریزی شده است.
- **سیاست امنیت حساب کاربری (رفع R-88)**: حداقل ۱۲ کاراکتر رمز، قفل حساب پس از ۵ تلاش ناموفق، تایم‌اوت ۳۰ دقیقه‌ای نشست جهت حفاظت از مهر دیجیتال.
- **تست دود گسترش‌یافته (رفع R-89)**: قبولی ۶/۶ تست خودکار شامل امضای مهر دیجیتال KMS و پایداری یادداشت‌های BCF.
- **شفاف‌سازی زمان RTO (رفع R-91)**: ۳۸.۲ دقیقه بازیابی پایگاه داده + ۱۰ دقیقه تشخیص قطعی = مجموعاً ۴۸.۲ دقیقه زمان قطعی e2e (احراز حد نصاب زیر ۱ ساعت).

- **ملاحظات عملیاتی باکت S3 در حالت Compliance Mode**:
  - *ایزوله‌سازی باکت لاگ*: باکت لاگ‌های امنیتی اختصاصاً برای مسیر `/audit` تنظیم شده و ثبت سایر داده‌ها توسط سیاست باکت رد می‌شود.
  - *عدم بازگشت‌پذیری نگهداری ۷ ساله*: حالت Compliance غیرقابل تغییر بوده و دوره ۷ ساله قبل از اولین ثبت داده تایید گردیده است.

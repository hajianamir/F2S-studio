# نقشه راه توسعه (Roadmap)

---

### فاز ۱: هسته محاسباتی و پایه (MVP - نسخه فعلی)
- هسته محاسباتی C++20 (روش‌های Hazen-Williams، Darcy-Weisbach و حل‌کننده Hardy Cross)
- محاسبات اعلان حریق NFPA 72
- سرویس .NET 8 API و ارتباط P/Invoke
- ورودی/خروجی IFC4 با xBIM
- مشاهده‌گر سه‌بعدی وب و نشانه‌گذاری BCF

### فاز ۲: توسعه BIM و هوش مصنوعی
- افزونه اختصاصی Revit
- چیدمان هوشمند اسپرینکلرها با یادگیری ماشین

# سند معماری نرم‌افزار (SAD) — نسخه پیاده‌سازی شده
**پلتفرم یکپارچه طراحی و شبیه‌سازی سیستم‌های حفاظت در برابر حریق**
*نسخه 1.0.0 (MVP) - ارزیابی انطباق NFPA 13 / NFPA 72*

---

## ۱. خلاصه اجرایی و پشته فناوری
- **هسته محاسباتی (+C++20)**: کتابخانه اشتراکی C++20 شامل الگوریتم‌های Hazen-Williams، Darcy-Weisbach، حل‌کننده حلقوی Hardy Cross و محاسبات افت ولتاژ مدار NAC و باتری با C ABI.
- **سرویس بک‌اند (.NET 8)**: سرویس REST API با معماری پاک و P/Invoke مستقیم، پشتیبانی از OpenAPI 3.1 و مبدل IFC4 مبتنی بر xBIM.
- **موتور قوانین**: قوانین نسخه به نسخه استانداردهای NFPA در قالب فایل‌های JSON مجزا.
- **رابط کاربری وب سه‌بعدی**: برنامه تک‌صفحه‌ای React و Three.js با قابلیت رندر سه‌بعدی نقشه حرارتی فشار، ثبت یادداشت BCF و پشتیبانی کامل از دو زبان و چیدمان RTL با فونت وزیرمتن.


### ۵.۳۳ فرض وابستگی زمانی فاز ۵ و دروازه خروج
- **فرض زمان‌بندی**: شروع فاز ۵ در سه‌ماهه دوم ۲۰۲۷ مشروط به بستن دروازه خروج فاز ۴ تا آوریل ۲۰۲۷ است (مدت بررسی ممیزی آتش‌نشانی کمتر از ۸ هفته و بدون نیاز به اصلاح و ارسال مجدد).
- **قاعده تعویق**: در صورت نیاز به ارسال مجدد یا فراتر رفتن زمان ممیزی از ۸ هفته، شروع فاز ۵ به سه‌ماهه سوم ۲۰۲۷ موکول خواهد شد.


### ۵.۳۴ ارزیابی یکپارچه گردش‌کار پایانی پلتفرم
- **گزارش ارزیابی**: فایل `benchmark/end_to_end_workflow_test_report.json` شامل اجرای موفقیت‌آمیز هر ۸ مرحله از ورود فایل BIM تا تولید گزارش نهایی ۲۸ صفحه‌ای همراه با ثبت مهر دیجیتال.

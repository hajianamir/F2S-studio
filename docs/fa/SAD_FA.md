# سند معماری نرم‌افزار (SAD)
**پلتفرم یکپارچه طراحی و شبیه‌سازی سیستم‌های حفاظت در برابر حریق**
*نسخه 1.0.0 (MVP) - ارزیابی انطباق NFPA 13 / NFPA 72*

---

## ۱. خلاصه اجرایی و چشم‌انداز
پلتفرم یکپارچه طراحی و شبیه‌سازی سیستم‌های حفاظت در برابر حریق، یک برنامه کاربردی ابری و ماژولار است که برای انجام محاسبات هیدرولیک، بررسی خودکار انطباق با ضوابط NFPA و مدلسازی BIM توسعه یافته است.

## ۲. معماری کلان سیستم
- **هسته محاسباتی (+C++20)**: کتابخانه پرسرعت با C ABI جهت اجرای افت فشار Hazen-Williams/Darcy-Weisbach، حل‌کننده حلقوی Hardy Cross و محاسبات افت ولتاژ NAC.
- **سرویس بک‌اند (.NET 8)**: سرویس REST API مبتنی بر Clean Architecture و CQRS جهت مدیریت پروژه‌ها، فراخوانی P/Invoke هسته C++ و مبدل IFC4 با xBIM.
- **موتور قوانین (Rule Engine)**: فایل‌های ساختاریافته JSON برای نسخه‌های مختلف NFPA 13 و NFPA 72.
- **رابط کاربری وب سه‌بعدی (React + Three.js)**: مشاهده‌گر سه‌بعدی با نقشه حرارتی فشار و پشتیبانی کامل از راست‌به‌چپ (RTL) و فونت وزیرمتن.
